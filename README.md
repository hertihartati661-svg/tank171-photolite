# Tank171 PhotoLite

A lightweight Android photo compressor. Choose a picture, set an approximate JPEG target size, compress on-device, save the result, and share the saved image.

## Features
- Android system photo picker
- Adjustable target size (100 KB–1 MB)
- JPEG quality control
- Save to `Pictures/Tank171PhotoLite`
- Share the saved image
- Image processing stays on the device

Target size is best-effort: some images cannot reach the selected size without substantial quality or dimension reduction.

## Build an APK
Push to `main` or open the **Actions** tab and run **Build Android APK**. The workflow uploads a debug APK as an artifact.
